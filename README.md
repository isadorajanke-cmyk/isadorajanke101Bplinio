# 🦋 O Mundo das Borboletas

Bem-vindo ao projeto **O Mundo das Borboletas**! Este é um site responsivo e interativo desenvolvido para explorar o universo fascinante, a biologia, a metamorfose e as curiosidades sobre as borboletas. 

O projeto foi construído utilizando tecnologias web fundamentais (HTML, CSS e JavaScript), servindo tanto como uma página informativa rica quanto como um demonstrativo prático de desenvolvimento front-end.

---

## 🎯 Objetivo do Projeto

O principal objetivo deste projeto é conscientizar e educar as pessoas sobre a importância ecológica das borboletas (como polinizadoras essenciais) através de uma interface atraente, moderna e fluida. Além disso, o projeto visa aplicar conceitos práticos de manipulação do DOM com JavaScript, estilização avançada e design responsivo.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

* **HTML5:** Estruturação semântica de todo o conteúdo da página (`<header>`, `<main>`, `<section>`, `<footer>`, tabelas e elementos multimídia).
* **CSS3:** Estilização visual, layout responsivo, uso de variáveis para paleta de cores (tons de roxo e lavanda) e centralização de mídia.
* **JavaScript (ES6):** Dinamicidade da página, controle de interações do usuário e possíveis componentes dinâmicos (como filtros de espécies ou galerias).

---

## ✨ Funcionalidades

* **Seção Informativa:** Detalhes sobre a ordem *Lepidoptera* e o papel das borboletas na natureza.
* **Linha do Tempo da Metamorfose:** Explicação passo a passo do ciclo de vida (Ovo, Lagarta, Crisálida e Adulta).
* **Vídeo Incorporado:** Reprodutor de vídeo integrado e centralizado com conteúdos educativos do YouTube.
* **Tabela de Espécies:** Listagem organizada contendo o nome comum, nome científico e características marcantes de borboletas famosas.
* **Design Responsivo:** Adaptável para leitura confortável tanto em computadores quanto em dispositivos móveis.
